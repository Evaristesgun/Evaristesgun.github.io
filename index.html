About

This website collects my mathematical notes, expository writing, and ongoing independent study projects. Current interests include linear algebra, mathematical analysis, abstract algebra, analytic number theory, representation-oriented mathematics, and the historical development of classical mathematical ideas.

Most documents are written in LaTeX and automatically compiled through GitHub Actions and deployed via GitHub Pages.
